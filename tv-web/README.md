# شاشة على تلفزيونات سامسونج وإل جي

نفس مشغّل شاشة اللي على أندرويد TV، بس مكتوب كصفحة ويب وحدة (HTML وCSS وJavaScript، بدون مكتبات غير hls.js) عشان يشتغل على:

- **إل جي** بنظام webOS (ملف `.ipk`)
- **سامسونج** بنظام Tizen (ملف `.wgt`)

التطبيق ما فيه قنوات. تضيف اشتراكك (حساب Xtream أو رابط M3U) ويطلع لك نفس شكل تطبيق أندرويد: الرئيسية مثل نتفلكس، أفضل 10، كمّل المشاهدة، المباشر بالأقسام وجدول البرامج، صفحة الفيلم أو المسلسل بالمواسم والحلقات، والمشغّل يكمّل من وين وقفت ويطلع لك الحلقة التالية في آخر 3 دقائق.

## وش الفرق عن نسخة أندرويد

- **ما فيه تسجيل بالجوال (QR).** تطبيقات الويب على التلفزيون ما تقدر تفتح سيرفر داخل الشبكة، فالبيانات تنكتب بالريموت (التلفزيون يطلع لوحة مفاتيحه لما تضغط OK على الخانة).
- **القوائم تنجاب من السيرفر كل ما تفتح التطبيق**، ما تنحفظ في التلفزيون. مع الاشتراكات الكبيرة ممكن يأخذ ثواني زيادة.
- **الجودة** تقدر تختارها في متصفح الكمبيوتر بس. على التلفزيون المشغّل حق الجهاز يختارها لحاله.
- البيانات (الاشتراك، قائمتي، وين وقفت) تنحفظ في التلفزيون نفسه، وما تطلع لأي مكان ثاني.

## الريموت

| الزر | وش يسوي |
|---|---|
| الأسهم | تتنقل بين العناصر |
| OK | تفتح أو تشغّل، وعلى خانة الكتابة تطلع لوحة المفاتيح |
| رجوع | ترجع خطوة، ومن الرئيسية يفتح الشريط الجانبي، ومرة ثانية يطلع من التطبيق |
| تشغيل / إيقاف | يوقف ويكمّل |
| تقديم / ترجيع | 30 ثانية |
| يمين ويسار والأزرار مخفية | 10 ثواني قدّام أو ورا |
| القناة + / − | القناة اللي بعدها أو قبلها في المباشر |

## البناء

تحتاج Node.js (عشان `ares-package` من LG) وبايثون:

```bash
bash tv-web/build.sh
```

يطلع لك في `tv-web/build/`:

- `io.github.saadharazi.shasha_1.0.0_all.ipk` لإل جي
- `Shasha.wgt` لسامسونج. **بدون توقيع** إلا لو عندك أداة `tizen` من Tizen Studio وشهادة (تحت).

## التجربة على الكمبيوتر

```bash
node tv-web/test/data.test.js
python -X utf8 tv-web/test/browser.py
```

الأول يجرب قراءة M3U وXtream والحلقات وأفضل 10. الثاني يفتح التطبيق في Chrome بمقاس 1920×1080 ضد سيرفر التجربة (`tools/mock-xtream.py`)، ويمشي بالأسهم وEnter وBackspace بدل الريموت: يضيف حساب Xtream، يفتح مسلسل، يشغّل حلقة، يتأكد من بطاقة الحلقة التالية ومن حفظ وين وقفت، يشغّل قناة مباشرة، وبعدين يضيف رابط M3U. الصور تنحفظ في `tv-web/build/screens/`.

تقدر تفتحه بنفسك كمان:

```bash
python -X utf8 tools/mock-xtream.py 8899
```

```bash
python -m http.server 8771 --directory tv-web
```

وافتح `http://localhost:8771` بمقاس الشاشة كاملة، والسيرفر `127.0.0.1:8899` واسم المستخدم وكلمة المرور `demo`.

## التثبيت على إل جي (webOS)

الطريقة الرسمية الوحيدة بدون المتجر هي **وضع المطوّر**:

1. سوّ حساب مطوّر (مجاني) في [webostv.developer.lge.com](https://webostv.developer.lge.com).
2. في التلفزيون: افتح متجر LG وحمّل تطبيق **Developer Mode**، سجّل دخول بنفس الحساب، فعّل **Dev Mode Status**، والتلفزيون يعيد التشغيل.
3. افتح Developer Mode مرة ثانية وفعّل **Key Server**.
4. في الكمبيوتر ثبّت أدوات LG:

   ```bash
   npm install -g @webos-tools/cli
   ```

5. أضف التلفزيون (IP التلفزيون من إعدادات الشبكة فيه، المنفذ 9922، المستخدم prisoner):

   ```bash
   ares-setup-device --add tv --info "{'host':'192.168.1.146','port':'9922','username':'prisoner'}"
   ```

6. خذ المفتاح من التلفزيون (يطلب منك العبارة اللي تطلع في تطبيق Developer Mode):

   ```bash
   ares-novacom --device tv --getkey
   ```

7. ثبّت وشغّل:

   ```bash
   ares-install --device tv tv-web/build/io.github.saadharazi.shasha_1.0.0_all.ipk
   ```

   ```bash
   ares-launch --device tv io.github.saadharazi.shasha
   ```

**الحدود بصراحة:**

- **وضع المطوّر ينتهي.** الجلسة لها عدّاد (يطلع في تطبيق Developer Mode، حوالي 1000 ساعة في الإصدارات الجديدة وأقل في القديمة). لو انتهى، التلفزيون يشيل التطبيقات اللي ثبّتها بنفسك. لازم تفتح Developer Mode وتضغط **Extend** قبل لا يخلص، والإنترنت لازم يكون شغّال.
- التطبيق ما يطلع في متجر LG، وكل تلفزيون تثبّته عليه بنفسك.

## التثبيت على سامسونج (Tizen)

سامسونج ما تقبل أي تطبيق إلا **موقّع بشهادة منها**، والشهادة مربوطة بالتلفزيون نفسه:

1. ثبّت [Tizen Studio](https://developer.samsung.com/smarttv/develop/getting-started/setting-up-sdk/installing-tv-sdk.html)، ومن **Package Manager** ثبّت **TV Extensions** و**Samsung Certificate Extension**.
2. في التلفزيون: افتح **التطبيقات (Apps)**، واضغط بالريموت 1 2 3 4 5 ورا بعض. تطلع نافذة **Developer mode**: فعّلها، واكتب IP الكمبيوتر، وأعد تشغيل التلفزيون.
3. في Tizen Studio افتح **Device Manager** وأضف التلفزيون بالـ IP (مثل 192.168.1.12) والمنفذ 26101. التلفزيون لازم يكون شغّال وعلى نفس الشبكة.
4. افتح **Certificate Manager** وسوّ شهادة **Samsung** (تحتاج حساب سامسونج). اختار TV، وسوّ شهادة مؤلف وشهادة موزّع؛ وهو يسوي شهادة الموزّع يضيف رقم التلفزيون (DUID) لحاله لو التلفزيون متصل. سمّها مثلًا `shasha`.
5. خل أداة `tizen` في الـ PATH (مكانها `tizen-studio/tools/ide/bin`) وابنِ من جديد، يطلع لك `Shasha.wgt` موقّع:

   ```bash
   TIZEN_PROFILE=shasha bash tv-web/build.sh
   ```

6. ثبّت على التلفزيون (اسم الجهاز من `sdb devices`):

   ```bash
   tizen install -n tv-web/build/Shasha.wgt -t <اسم-التلفزيون>
   ```

**الحدود بصراحة:**

- **الشهادة شرط.** الـ wgt بدون توقيع ما ينثبّت، والتوقيع يحتاج Tizen Studio وحساب سامسونج.
- **الشهادة مربوطة بالتلفزيون (DUID).** تلفزيون ثاني يحتاج تضيفه للشهادة وتوقّع من جديد.
- **الشهادة لها مدة.** لو انتهت لازم تسوي وحدة جديدة وتوقّع وتثبّت من جديد.
- وضع المطوّر في التلفزيون ممكن ينطفي بعد تحديث النظام، وترجع تفعّله بنفس الطريقة.
- التطبيق ما يطلع في متجر سامسونج.

## الملفات

| الملف | وش فيه |
|---|---|
| `index.html`, `app.css`, `app.js` | الواجهة والتنقل بالريموت والمشغّل |
| `data.js` | الاشتراكات وXtream وM3U وقائمتي ووين وقفت (نفس منطق `Library.java` و`Store.java`) |
| `lib/hls.min.js` | [hls.js](https://github.com/video-dev/hls.js) 1.7.3 (رخصة Apache 2.0) لتشغيل HLS في متصفح الكمبيوتر |
| `fonts/` | خط Tajawal (رخصة OFL) |
| `appinfo.json` | تعريف تطبيق إل جي |
| `config.xml` | تعريف تطبيق سامسونج: يسمح بكل الروابط (`access origin="*"`) والإنترنت وأزرار الريموت |
| `build.sh` | يبني الملفين في `build/` |

## مكتوب لمتصفحات التلفزيونات القديمة

تلفزيونات إل جي بنظام webOS 4 فيها متصفح بمستوى Chromium 53، وسامسونج 2021 حوالي Chromium 76. عشان كذا الكود ما يستخدم `async` ولا `?.` ولا `padStart`، والتنسيق ما يستخدم `inset` ولا `gap` في flex ولا grid. لو تعدّل، خلك على نفس الشي.

**ما تجرّب للحين على تلفزيون حقيقي**، بس في Chrome على الكمبيوتر. أول تجربة على التلفزيون ممكن تطلّع أشياء تحتاج تعديل، خصوصًا تشغيل البث بمشغّل الجهاز.
